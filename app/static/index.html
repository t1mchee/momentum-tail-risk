The book today

The 12-1 sort rebuilt on point-in-time index membership, then the winner-minus-loser loading on each of eight reference series, standardised against 500 random books matched on leg size and capitalisation. The sort is the only thing that differs between the real book and the null, so the z-score is attributable to the momentum sort and not to the universe.

The analogue engine

Four stages, and you can watch each one. A numerical retrieval finds the nearest historical states; a date-constrained text encoder finds the nearest episodes by what the loser leg was priced on; three model roles argue over the merged record behind two gates; a verdict comes out. The engine's own limits are in the record, so the panel can refuse to rule rather than guess.

The live seat

One model seat, run live against the Anthropic API on a filing you pick. Same schema, same system prompt, same 18,000-character window and the same quote gate as the proof of concept. The schema has no numeric field, so the model cannot return a number; the decline path is a first-class answer; and every accepted record carries a verbatim span that is string-matched against the source before it is kept.
